# SQL Data Analysis Project

## 📌 Project Overview

This project focuses on extracting and analyzing structured data using **SQL. Various SQL queries are used to retrieve information, filter records, perform calculations, group data, and combine information from multiple tables.

## 🛠️ Tools Used

* SQL
* pgAdmin

## 📊 SQL Concepts Used

* `SELECT`
* `WHERE`
* `ORDER BY`
* `GROUP BY`
* Aggregate Functions (`SUM`, `AVG`, `COUNT`, `MAX`, `MIN`)
* `JOIN`
* Filtering and sorting data
* Data aggregation and analysis

## 🎯 Objective

To learn how to manipulate, query, and analyze structured data using SQL.

## 📁 Project Deliverables

* SQL query file (`.sql`)
* Database tables
* Data analysis queries
* Query results and insights

## 📈 Outcome

This project demonstrates the ability to write SQL queries for data extraction, manipulation, and analysis using PostgreSQL.
